# Glass Berry Club · 유리딸기 클럽

무중력 공간을 떠다니는 유리 딸기. 딸기를 하나씩 띄우고, 천천히 부딪히는 맑은 유리 소리를 들어 보세요.

**▶ https://i0kyung.github.io/glass-berry/**

- 끌어서 살짝 밀기 · 빈 곳 누르기 · 딸기 누르면 색 변경
- 가운데 **딸기 띄우기** 버튼으로 한 알씩 추가 (최대 18알)
- **문구** 버튼: 배경 큰 문구·작은 문구 편집, 시간·날짜 표시 켜기/끄기
- 폰: **흔들기** 버튼으로 센서를 켜면 기울이면 흐르고 흔들면 부딪혀요
- 소리는 Web Audio로 실시간 합성

Three.js (MeshPhysicalMaterial transmission) · 단일 `index.html`
